# Assets

**Art direction:** An original portrait mobile combat world set above the neon-gothic city of Nocturne. Black marble surfaces, ultraviolet eclipse energy, eclipse cyan targeting marks, and restrained crimson blood magic create strong touch-screen readability. Shapes are clean and high contrast, with readable enemy and objective silhouettes rather than detailed borrowed visual language.
