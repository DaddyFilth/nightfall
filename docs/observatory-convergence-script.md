# The Observatory — Branch Convergence Script

## Purpose

The Observatory is Mission Three’s shared destination. It does not erase the Blackout Protocol choice: instead, it changes the entry narration, tactical advantage, and three operation scenes before both routes reach the same core floor. This approach preserves player authorship while keeping the vertical slice’s content scope proportional.

| Blackout Protocol route | Observatory entry | Tactical context | Shared destination |
|---|---|---|---|
| **The Last Platform** | A survivor-led service entrance mapped by Vesper’s evacuees. | Civic trust and a quiet approach through caretakers’ corridors. | The first Observatory relay core. |
| **Following Static** | A lattice gap decoded from the captured courier cipher. | A narrow red-window infiltration with precise relay knowledge. | The first Observatory relay core. |

Each route has three locally persisted operations—entry, defense-gap navigation, and core-floor preparation—followed by a saved convergence result. The implementation remains device-local and UI-driven. It does not represent a networked campaign ledger, cloud synchronization, a production Godot save, or fully playable 3D mission content.
