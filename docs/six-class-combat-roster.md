# Blood & Brass: Six-Class First-Person Combat Roster

Blood & Brass is a **first-person shooter** set in a fictional 1500s world where vampire privateers, cathedral brasswork, cursed navigation engines, and black-powder weapons collide. Every playable class is available locally from the outset. The roster is designed around readable counterplay, rather than paid progression or hidden statistical advantage.

## First-person readability contract

Each class has a distinct class callsign, weapon pair, reticle treatment, reload rhythm, ability title, and status message. The player’s active selection is made at the native Drowned Chart hub before a campaign mission begins. The class’s primary weapon drives its projectile damage profile, while its secondary weapon drives the active boarding ability. Every ability keeps a visible windup, range limit, cooldown, or recovery window.

## Fair-play boundary

Class identity affects local playstyle but is neither purchased nor upgraded. Cosmetic rewards remain presentation-only. The supplied icon is used only as private visual-reference guidance while creating original Blood & Brass art; it is not displayed in the companion roster, native hub, or combat HUD.
