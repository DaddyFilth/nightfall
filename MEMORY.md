# Build Memory

The app is a portrait Expo prototype, intentionally distinct from the attached production-game request. It uses no Godot engine, backend, multiplayer transport, third-party ads, real entitlement, receipt validation, telemetry endpoint, or checkout provider. Any future production work should replace the local adapters behind platform billing, advertising, account, and transport interfaces rather than promote this presentation state to a production entitlement.

The visual target asset URL reserved for the build is `/manus-storage/nightfall-combat-visual-target_f6d3dfca.png`. It defines the black-marble, ultraviolet, cyan, and crimson direction used by the interface.
